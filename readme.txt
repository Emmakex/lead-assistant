Focused AI chatbot and lead generation assistant for WordPress.

== Description ==

Lead Assistant is being built as a simple, focused conversational lead engine for WordPress.

The normal setup is intentionally small: describe the business, define the commercial goal and add the shortcode `[lead_assistant]`.

The assistant is governed by a conversation policy designed to keep discussions focused on the configured business instead of becoming a general-purpose chatbot.

This repository is currently in foundation development and is not yet a production release.

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/`.
2. Activate Lead Assistant.
3. Open Lead Assistant in WordPress administration.
4. Describe the business and the commercial goal.
5. Add `[lead_assistant]` to a page.
